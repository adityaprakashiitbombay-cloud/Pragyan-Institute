⚙️ 3. Admin & Educator Master Control Center 11 Key Features

  • 📈
    STATS Real-Time Executive Summary: Interactive overview counters tracking active enrollments, monthly revenues, outstanding dues, and attendance.
  • 💰
    ANALYTICS Per-Educator Collection Breakdown: Separated financial analytics isolating each educator's fee collections across Cash vs. UPI.
  • 📅
    AUTO 10-Day Staggered Rolling Billing Engine: Days 1–6 raise invoices batch by batch (10th & 12th, then 9th & 11th, 8th, 6th–7th, 1st–5th, Special English) and days 7–10 chase unpaid balances. Days 11–31 are a deliberate rest state.
  • 🔁
    IDEMPOTENT Duplicate-Billing Immunity: Every accrual runs inside apply_monthly_fee with FOR UPDATE row locking and a BILL-STUDENT_ID-YYYY-MM key, so a retried cron — or a mid-month batch transfer — can never charge the same month twice.
  • ✉️
    RESEND Verified-Domain Email Engine: Billing statements and computerized receipts dispatched from noreply@pragyaninstitute.com over the Resend API.
  • 📮
    QUOTA 100-Email/Day Quota Guard: A live remaining-slot counter on the dashboard, and a hard reservation check that defers the overflow rather than failing a batch run halfway through the free-tier ceiling.
  • 🏷️
    MODAL Post-Admission Fee Adjustments: Dedicated vouchers for permanent rate modifications, merit fee concessions, special add-ons, and balance waivers.
  • 🆔
    YYCCSS Sequential Student ID Generator: Collision-proof YYCCSS barcode IDs (2-digit year + class code + serial 01–99) minted under a row lock so concurrent admissions cannot clash.
  • 🔒
    GUARD Financial Cascade Deletion Guardrails: Strict security protection blocking accidental deletion of student accounts carrying pending uncleared dues.
  • 📋
    AUDIT Searchable Institutional Audit Trail: Immutable history of every educator action, filterable by teacher, date and event category. Only Managing Director Chandan Kumar may purge it, and a purge never touches dues, revenue or receipts.
  • 👤
    SETTINGS Admin Profile & VPA Billing Hub: Director profile card with photo upload, UPI VPA configuration, 1-click date-of-birth password reset for students, and master password security.
